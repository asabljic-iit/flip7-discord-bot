# Privacy Policy for Flip 7 Discord Bot

**Last Updated:** September 3, 2026

This Privacy Policy explains how the **Flip 7 Discord Bot** ("the Bot", "we", "us", or "our") handles user information when you interact with or add the Bot to your Discord server, Direct Messages (DMs), or group chats.

We prioritize user privacy and adhere to a strict data minimization principle: **we only process the minimum temporary data required to run card game sessions.**

---

## 1. Information We Process

To operate the game, the Bot temporarily accesses and stores the following data in volatile memory (RAM):

* **Discord User IDs & Display Names:** Used to identify active players, display turn orders, render scoreboards, and ensure proper turn permissions during game sessions.
* **Channel & Guild IDs:** Used to isolate active game lobbies and prevent commands/interactions from interfering with other channels or servers.
* **Game Session State:** Temporary records of player hands, cards drawn, scores, and active status during a match.

---

## 2. How We Use Information

The collected data is strictly used for the following operational purposes:

* Creating and managing matchmaking lobbies.
* Enforcing game rules, turn cycles, card resolution, and score tallying.
* Preventing cross-channel session conflicts.

**We do not use your data for advertising, marketing, profiling, or tracking across other applications.**

---

## 3. Data Retention & Storage

* **Volatile Memory Only:** All active game states, player hands, and session data are stored exclusively in volatile runtime memory (RAM).
* **Automatic Clearing:** Game session data is automatically purged from memory when a match concludes, when a session is stopped via `/flip7_stop`, or when the Bot service restarts.
* **No Persistent Storage:** The Bot does not store message history, personal user details, or chat content in external databases, log files, or persistent storage disks.

---

## 4. Third-Party Data Sharing

* **No Data Selling:** We do not sell, rent, trade, or transfer any user data to third parties.
* **Discord Platform:** Because the Bot operates entirely within the Discord platform, your interactions with the Bot are also subject to the [Discord Privacy Policy](https://discord.com/privacy).

## 6. Data Security & Rights

* **User Control:** You can remove the Bot or stop data processing at any time by leaving a game lobby, finishing an active match, stopping the session via `/flip7_stop`, or removing/uninstalling the Bot from your server or user account.
* **Data Requests:** Because we do not store persistent user profiles or databases, there is no permanent stored personal data associated with your Discord account to modify or delete.
